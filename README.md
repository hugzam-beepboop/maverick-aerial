# Brush Country Aerial

Public coming-soon site for drone work out of Eagle Pass / Maverick County, Texas.

**Waitlist only.** This page does not offer commercial flights, book jobs, or claim an FAA Part 107 certificate.

Brand is locked: **Brush Country Aerial**. Not Maverick Aerial. Not Precision. Not Drone Services.

## Live files

- `index.html` — the whole site. Open it in a browser even if Grok is gone.
- Edit the email in `index.html` (`CONTACT_EMAIL`) before you share the link.

## Put it on the internet (GitHub Pages)

1. Open https://github.com/hugzam-beepboop/maverick-aerial/settings/pages
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save. After a minute the site is:
   `https://hugzam-beepboop.github.io/maverick-aerial/`

Repo folder is still named `maverick-aerial`. That is the GitHub slug, not the company name. Custom domain later: add a `CNAME` file with the domain and point DNS. Do not do that until you own the domain.

## Rules baked into the copy

- No legal name on the public page
- No employer / appraisal-office language
- No prices, no aircraft model, no fake portfolio
- Commercial work starts after Part 107 — the FAQ says that in English and Spanish
